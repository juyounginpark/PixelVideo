# 레퍼런스 3·4 적용 범위

사용자가 제공한 V3 편집 분류를 제작 사양으로 적용했다. 아래 정지 증거로 보이는 디자인과 시간 기반 관찰을 구분한다.

| 근거 | 직접 확인한 화면 | 구현 연결 |
|---|---|---|
| `research/reels_v2/ref3/12.0.png` | 큰 제목, 보조 패널, 아래 자막, 단순한 캐릭터, 네온 정보 공간 | 작은 상태 패널/정보 계층. 네온 배경을 기본 월드로 복제하지 않음 |
| `research/reels_v2/ref4/02.0.png` | 웃는 눈/볼, 손동작, 머리 주변 십자, 큰 강조 자막 | 표정과 손의 반응, 타깃 주변 십자 파티클, 짧은 강조 글자 |
| 사용자 V3 원문 | Punch Zoom, Dark Focus, 매치 컷 등 편집 동작의 요구 사양 | 사건 프레임과 대상에 연결한 편집 기능 |

단일 프레임으로 원본의 정확한 줌 배율·팝 시간·입자 수·SFX를 측정했다고 주장하지 않는다. 110% 줌, 0.55초 파티클, 최대 28% 배경 어둡게 등은 사용자가 제시한 범위에 맞춘 이번 시스템의 실행값이다.

실제 6초 샘플은 질문→물체 상승에 놀람→회전 관찰→색 변화 확인을 담은 편집 시험이다. 과학적 발견이나 신규 주제로 주장하지 않는다. 샘플과 최종 릴스에서 사용한 효과/프레임은 각 작업의 `effects.json`과 `camera_qa.json`, `ui_qa.json`에서 확인한다.

소리의 적합성을 원본을 청취한 것처럼 보고하지 않는다. 기존 로컬 합성 음원 중 메타데이터와 사건 목적이 맞는 것을 사용하고 LUFS/피크/동기화 검사를 별도로 한다.
