# EP05 선정 및 사실 검증

## 공급원과 선정

- 공급원: 기존 [나무위키 미스터리 관련 정보](https://namu.wiki/w/미스터리%20관련%20정보), 그 아래 자연과학 목록.
- 기존 로컬 원문: `research/namuwiki/listing.txt` 92행, 항목 **브라질너트 효과**. `TOPIC_LIST_DRAFT.md`의 기존 15개 검토 주제 중 1번이다. 순번을 인기 순위로 해석하지 않았다.
- 기존 `prompts/MYSTERY_100_v1.md`의 시각적 변화·역할극·원문 항목·검증·제외·중복 기준을 적용했다. 범죄/피해/정치/의학·민감 개인사 주제가 아니다.
- 중복 대조: 기존 움직이는 돌 기획, 미스터리 자판기, 브로켄, 가시도마뱀 에피소드와 제목·개념이 다르다. 생산 폴더/기존 대본에서 이 소재의 제작 결과를 찾지 못했다.
- 시스템과 6초 효과 샘플 QA 이후 선별했다. 기존 나무위키 원본·15개 목록·선별 프롬프트를 수정하지 않았다. 새 자동 추천기·스케줄러·제작 큐를 만들지 않았다.

## 사실 근거

[Gajjar 외, Scientific Reports 11, 8352 (2021)](https://doi.org/10.1038/s41598-021-87280-1). 저자 소속 대학의 [원문 PDF](https://personalpages.manchester.ac.uk/staff/nico.gray/Papers/SR_11_2021.pdf)를 내려받아 Results, Discussion, Methods를 읽었다. 로컬 `primary_paper.pdf` / `primary_paper.txt`.

| 주장 | 원문 위치 | 표현 |
|---|---|---|
| 혼합 견과에서 큰 견과 일부가 올라오고 땅콩이 내려갔다 | Results, p.2 | 큰 견과 상승과 작은 땅콩의 하강을 함께 보여줌 |
| 올라온 길쭉한 견과는 먼저 수직에 가깝게 회전했다 | Results, pp.2–3 | 회전 단계 뒤 상승; 수직으로 세우기만 하면 된다는 단정 금지 |
| 주변 작은 땅콩의 하강도 필요했다 | Discussion, pp.3–4 | 빈 공간으로 땅콩이 내려가고 큰 견과가 올라감 |
| 모든 큰 견과가 올라오지는 않았다 | Results/Discussion | 남은 견과도 마지막에 보여줌 |
| 실험은 전단 상자와 반복 촬영을 사용했다 | Methods, p.4 | 내부 모식도/연구 재구성 표기. 영상의 초·흔든 횟수를 실제 측정값으로 표시하지 않음 |

이 작품은 문헌에 근거한 키프레임 설명 애니메이션이다. DEM 입자 해석, 실제 X선 데이터 재생, 모든 흔들기 조건에서 같은 결과라는 주장은 하지 않는다. 원리 설명은 이 연구가 관찰한 길쭉한 견과 사례에 한정한다. 땅콩 입자가 서로 통과하는 인상을 주지 않도록 경로를 분리해 검수한다.

음원은 기존 카탈로그의 exploration/observation 메타데이터를 확인한 원곡과 허용된 로컬 SFX만 사용한다. `curious_desert_100`은 파일명이 아니라 메타데이터/명시 ID로 고정한 선택이며 사막 주제를 공급하는 기능이 아니다.
