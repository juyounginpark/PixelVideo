# V6 구현 범위

기존 Blender/Pillow/FFmpeg, Galmuri 두 폰트, 민수 리그, 팔레트, 로컬 음원을 유지한다. EP09 원본과 소재 공급 자료를 수정하지 않는다.

구현:
- audit.py: 전체 디코드와 실제 출력 프레임, 합성 기록의 자막 교체 시점 기록.
- directors.py: 컷과 독립된 자막 타임라인, 읽기 시간 검사, 이어지는 구절 유지; 설명 진입/복귀/같은 월드 상태 계약 검사.
- STYLE_SPEC.json: 상시 제목·챕터·출처·외곽 프레임 제거, 모드·폰트·색상 의미·출력 규칙.
- sample_render.py: 기존 EP09 에셋의 10초 행동→표면 비교→복귀 샘플. 540×960 실제 3D, 한 작업자.
- sample_compose.py: 1080×1920 별도 픽셀 UI, 정수 nearest 확대, 4프레임 등장, 5.5초 첫 구절 유지, 약한 고정 스캔라인.

기술 검사와 시청 경험 판정을 분리한다. 출력 프레임 비교는 실시간 재생·청취 또는 대중 반응 검증을 대신하지 않는다.

완료: 기존 캐시에서 EP10 리쿠르고스의 컵 선정·독립 원문 검증, 32초 KO/EN 제작, 로컬 BGM/SFX 합성, 전체 960프레임 디코드·폰트·자막 충돌·프레이밍·피크·접지·복귀 상태·캐시·원본 보존 기술 검사. 기술 게이트 통과, 편집 품질 자동 승인은 하지 않았다.

실제 출력 검수 후 재작업: 잘린 대상/캐릭터 구도, 조명 왕복 불연속, 색과 자막 시점, 발 접지, 조사 컷 걷기, 발견 자막의 약한 강조. 접지는 월드 6컷만, 걷기는 S02만 다시 렌더했다. 마지막 재합성은 KO/EN 각각 UI 7컷과 동일 오디오를 재사용했다.

최종 결과: exports/MINSU_EP10_V6_LYCURGUS_KO.mp4, EN.mp4; ep10/REPORT.html 및 review/final/technical_qa.json, EDITORIAL_QA.md. 비교 이미지와 실제 렌더/합성 시간은 DELIVERY.json에 기록했다.

Git: 생성물 제외 규칙을 추가하고 새 규칙에 해당하는 기존 생성물 15,156개를 추적 해제했다. 로컬 파일·기존 커밋 이력·소재/폰트/재사용 음원/QA 기록은 유지했다. 커밋은 하지 않았다.

남은 한계: 실제 실시간 재생/청취와 대중 테스트는 미실시. 4–8초 조사 구간의 리듬, 잔 장식의 정밀도, 시선/손 연기는 더 개선할 수 있다. 광학은 설명용 애니메이션이며 완전한 분광 계산이 아니다. 새 소재별 3D 어댑터는 추가 설계가 필요하며 모든 소재의 동등한 자동 연출 품질을 보증하지 않는다. 모델 교차/UV/관절 검사는 일반적인 완전한 솔버까지 구현되지 않았다.
