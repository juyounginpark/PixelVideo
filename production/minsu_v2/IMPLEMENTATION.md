## 우선 규칙

- V2는 이전 고정 22.5% 헤더·상시 대사창·무음 전용 규칙을 대체한다.
- 36초 EP04의 9컷 시간: 0 / 1.8 / 4.5 / 8 / 12 / 17 / 22 / 27 / 32 / 36.
- 원본 1~4는 references에 있다. research/reels_v2의 직접 추출 프레임으로 관찰했다. 관찰하지 않은 오디오나 제작 도구는 추정하지 않는다.
- 모델·팔레트·리그 고정, 전경/중경/배경, 표정과 몸짓 동기화, 사건 전후 변화 확인.
- 피부 외부 비늘 사이 모세관을 보여준다. 물의 피부 투과·혈관 흡수·검증되지 않은 입 펌프를 만들지 않는다.
- 젖은 모래만으로 음수에 충분하다고 표현하지 않는다. 실제 자유수가 공급되고 통로에 모이는 조건을 보여준다.
- 연구의 방사형 이동을 입 방향으로만 흐르는 일방통행 펌프로 묘사하지 않는다.
- TTS 없음. 하나의 오리지널 연주 루프와 이벤트 효과음. 출처·제작 방식·메타데이터·스템 저장.
- UI/자막은 1080p 별도 합성, 사건/얼굴 가림 확인. 제작 메모를 UI 문구로 넣지 않는다.
- 전체 자동 과학 리서치/일반 대본 생성/물리 유체 해석기를 구현했다고 주장하지 않는다.

## 승인 전 확인

샘플 프레임 → 중요 동작 전후 → UI 검수 → 수정 → 전체 렌더 → 전체 디코드/오디오 분석.
정량 검사는 재미·인지·시청 지속률의 실측을 대신하지 않는다.
