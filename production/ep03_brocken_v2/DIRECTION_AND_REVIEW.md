# EP03 v2 — 28초 행동 중심 수정본

2026-10-12 / U-073. 사용자 평가를 반영한 재제작. 기존 v1은 보존한다.

## 변경

- 42초→28초. 반복적인 옆 이동·몸 낮추기 구간을 압축하고 확인 행동에 인과관계를 부여한다.
- 기존 12fps 원본→24fps 원본. 프레임마다 새로 촬영한 동작이며 단순 배속이나 프레임 보간이 아니다.
- 팔꿈치·무릎 관절, 눈 깜빡임, 눈썹과 입 모양, 뒤로 멈칫하는 반응, 뒤돌아보기 추가.
- 안개 속 형상은 처음 0.7초에 명암이 드러난다. 형상이 자율적으로 움직이는 귀신이나 시간차를 두고 따라오는 것으로 만들지 않는다.
- 빛·몸·안개의 도식은 빛 도착→빛 차단→그림자 형성→일치하는 팔 동작을 순서대로 보여준다.
- 사진은 전체→확인된 그림자 부분으로 연속 확대한다. 사진에 새 형체나 광륜을 합성하지 않는다.
- 다마고치 기기를 첫0.8초와 끝1.1초에 강조. 본편은 얇은 민트 프레임과 내용 영역90.25%로 축소된 장식 구조를 사용한다.
- 자막은 최종 출력에서 약32px 이상이 되도록34px로 합성. 최대2줄. 실제 자료 출처는 별도 하단22px.

## 타임라인

| 시간 | 연출과 새 정보 |
|---|---|
| 0~2.75 | 걸음을 멈추고 안개 속 형상을 발견. 팔을 올리는 과정과 동시 그림자 동작 |
| 2.75~3.8 | 놀란 얼굴, 팔을 움츠림. 짧은 제목 |
| 3.8~8.5 | 천천히 올렸다 갑자기 내리고, 다시 확인한 뒤 옆으로 한 발. 그림자와 정확히 동시 |
| 8.5~10.6 | 몸을 움츠리고 고개를 뒤로 돌림. 읽을 문구 없이 반응으로 전달 |
| 10.6~14.5 | 민수의 뒤돌아보기에 연결되는 역방향 구도에서 해를 직접 보여줌 |
| 14.5~20.5 | 빛 이동·차단·그림자 등장·동작 일치가 이어지는 도식, 정체 공개 |
| 20.5~25.5 | 실제 사진 전체에서 그림자 부분으로 확대, 크기 착시 설명 |
| 25.5~28 | 새로운 확인 동작을 마치고 기기 프레임 복귀. 역재생 없음 |

## 사실과 자료

과학 근거와 사진 라이선스는 ../ep03_brocken/SCRIPT_AND_SOURCES.md를 따른다. 같은 Mick Garratt 사진을 사용하며 원본 전체에서 크롭 확대한다. 화면에 촬영자·CC BY-SA 2.0 표시. 사진 확대 편집도 동일 라이선스 조건을 유지한다.

민수의 체험, 표정, 대사는 창작 각색이다. 3D 실루엣은 동일 포즈를 참조하는 도식적 재현이며 대기 광학의 물리 시뮬레이션이 아니다.

## 검수 기준

정지 시안·디코드 통과만으로 애니메이션을 승인하지 않는다. 손의 올림/내림, 멈칫, 발 이동, 뒤돌아보기의 연속 프레임을 별도로 검토한다. 화면 변화량은 변화의 존재 확인에만 쓰며 몰입감·시청 유지율 지표로 취급하지 않는다. 실제 휴대폰 UI와의 겹침은 별도 미확인 항목이다.
