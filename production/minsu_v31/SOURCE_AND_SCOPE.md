# 기존 공급과 과학 설명 범위

선정 상태 업데이트: 5초 발견 샘플의 실제 완성 프레임과 디자인 비교를 검토한 뒤 이 소재로 EP06 제작을 확정했다. 확정 출처·원문 해시·줄 위치는 `ep06/source_receipt.json`, 게이트 기록은 `ep06/sample_review/GATE.md`에 있다. 아래는 후보 검토 당시의 기록이다.

2026-10-12 (Asia/Seoul). 제작 후보: **얼음이 미끄러운 이유**.

공급은 기존 `research/namuwiki/TOPIC_LIST_DRAFT.md` 3번과 `research/namuwiki/listing.txt`의 얼음 항목이다. 자연과학 목록의 기존 저장 자료에서 읽었고 새 주제를 추가하지 않았다. 기존 자판기·브로켄·가시도마뱀·브라질너트 제작물과 움직이는 돌 기획에 중복되지 않는다. 움직이는 돌에서 얼음이 등장했다는 사실과 이번 마찰 주제는 구분했다. 후보 선별에는 기존 `prompts/MYSTERY_100_v1.md`의 시각적 변화·실제 항목·검증·피해 사건 제외·중복 기준을 적용했다. 얼음 위 민수의 행동은 피해 사건이나 실제 목격담이 아닌 가상 역할극이다.

5초 샘플 게이트 전에는 제작 후보이며 자동 선택기·큐·스케줄러를 새로 만들지 않는다. 공급 파일과 기존 영상의 해시는 `review/preservation_before.json`으로 보존 확인한다. 소재별 씬 구현은 공급기에 주제를 하드코딩한 것이 아니라 이번 에피소드의 명시적 렌더 어댑터다.

## 직접 확인한 1차 근거

1. Weber 외, **Molecular Insight into the Slipperiness of Ice**, J. Phys. Chem. Lett. 9, 2838–2842 (2018), [DOI](https://doi.org/10.1021/acs.jpclett.8b01188). [연구기관 원문](https://ir.amolf.nl/pub/10003/16396OA.pdf)을 `review/ice_2018.pdf`로 내려받아 본문을 읽었다.
2. Liefferink 외, **Friction on Ice: How Temperature, Pressure, and Speed Control the Slipperiness of Ice**, Phys. Rev. X 11, 011025 (2021), [원 논문](https://journals.aps.org/prx/abstract/10.1103/PhysRevX.11.011025). Abstract, Popular Summary에서 조건 의존성을 확인했다.
3. Bore 외, **Why ice is so slippery**, [arXiv:2603.11539](https://arxiv.org/html/2603.11539v1). 접촉 마찰열의 중요성을 제시하는 프리프린트의 Abstract/Introduction을 확인했다. 원인에 관한 이견을 점검하는 데만 사용하며 동료심사 완료나 최종 합의로 표현하지 않는다.

## 재현·권한 범위

분자·궤적·신발·강철 구슬은 직접 작성한 Blender 설명용 모델이다. 계산된 분자동역학, 실측 궤적, 실제 X선 사진, 정확한 수소결합 수나 분자 간 거리로 제시하지 않는다. 내부/경로/접촉 비교에 모식도 라벨을 넣는다. 두 강철 구슬은 같은 편집상 속도로 움직이며 다른 마찰 방향·크기를 설명한다. 온도 수치 이외의 허구 수치는 화면에 넣지 않는다.

논문의 도판·사진은 영상에 복제하지 않는다. 2018 PDF는 비상업·변경 제한 라이선스이므로 증거 열람용으로 보존한다. 원 사실을 바탕으로 자체 도식을 만들며 외부 도판을 변형해 사용하지 않는다. 음원은 기존 로컬 카탈로그의 상업·SNS 사용 허용 메타데이터가 있는 프로젝트 자체 합성 BGM/SFX만 재사용한다. TTS 없음.

폰트: 기존 Jua(디스플레이), Nanum Gothic ExtraBold(설명), Galmuri11-Bold(마이크로 라벨)의 프로젝트 내 원본과 라이선스를 재사용한다. 화살표는 설치된 Segoe UI Symbol로 래스터화하며 폰트 파일은 배포물에 복사하지 않는다.
