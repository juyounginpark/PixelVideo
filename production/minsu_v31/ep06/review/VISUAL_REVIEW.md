## 편집·미술 판단

EP05의 8–27초 동일 상자 전체 구도와 달리 전신→접촉부→두 층 단면→소수 분자 경로→발견→인물→조건 비교→측면→전후→결론으로 정보 단위가 바뀐다. 같은 시각화 모드를 연속 3컷 쓰지 않았다. 화면만으로 표면층 이동과 접촉체 진행의 순서를 볼 수 있지만, 이것이 모든 조건의 마찰을 증명한 물리 계산은 아니다. 모식도·연구 범위·온도 조건을 화면에 표시했다.

HOOK/EXPLANATION/IMPACT/MICRO/FACT/RESULT를 크기·서체·등장 방식·용도로 분리했다. FACT_PANEL은 온도 실험의 맥락을 전달하고 MICRO_LABEL은 대상·층·조건을 식별한다. 강조 색은 행 번호가 아니라 의미 단어에 적용했다. 네이비 공간/청색 얼음/따뜻한 인물·이동층의 팔레트와 일관된 윤곽을 확인했다.

`../../review/FINAL_REFERENCE_COMPARISON.jpg`에서 실제 Ref3·Ref4·EP05·EP06의 후킹/개념/정보 장면을 나란히 보았다. Ref3의 개념 오브젝트 변화와 Ref4의 인물→실험→사례 전환을 설계에 반영했다. 레퍼런스의 원본 제작 도구, 실시간 카메라 수치, 음성 내용을 관찰한 것으로 주장하지 않는다. 제작자의 전체 영상보다 낫다는 순위나 전문성 점수를 부여하지 않는다.

실제 네이티브 크롭의 외곽 계단과 재질 픽셀을 확인했다. 실제 합성기 출력의 UI 바깥 2,000,061픽셀이 원본 Nearest 2배와 정확히 같았다. 한글은 그 뒤 최종 해상도로 그린다. MP4 압축 결과까지 수학적으로 무손실 픽셀이라고 주장하지 않는다.
