U-088/089를 단일 활성 명세로 삼는다. EP06 실제 프레임과 ref3/ref4의 사건 직전/직후를 비교해 타이밍의 목적을 기록한다. 기존 목록 내 암흑물질을 제작 후보로 검토하되 6초 원리 샘플과 폰트·인물·미술 검수를 먼저 한다. 샘플 통과 뒤 중복 검사와 원문 해시를 포함해 소재를 확정한다. 주제 공급 파일은 수정하지 않는다. NASA의 관측과 추론 설명을 대조하고, 별의 움직임과 필요 중력·추가 질량 사이의 인과를 조건부로 설명한다. 빛나는 안개를 실제 관측한 암흑물질처럼 그리지 말고, 헤일로는 추론 모형이라고 표시한다. 민수는 관측·비교·모형 조작에 참여한다. 동일 반지름의 예상/관측 궤적을 비교하고 속력과 각속도를 혼동하지 않는다. 시작의 불일치를 결말의 질량 추론으로 해결한다. 정체는 미확인임을 유지한다. 한글 픽셀 DISPLAY/BODY 두 계열, 영어 보조 자막, 고해상도 독립 UI, 정수 확대, 짧은 의미 단위 자막을 사용한다. 컷별 SceneSpec에 11개 사건 필드를 넣고 카메라·캐릭터·효과음은 한 사건 프레임을 공유한다. 캐시 키를 3D/UI/audio/encode로 분리하고 부분 수정 테스트를 한다. 프리뷰→문제 컷 수정→최종 렌더→전체 디코드와 실제 프레임·연속 동작 검수를 수행한다. 실제 재생/사람의 청취/시청자 테스트 미실시를 자동 QA로 대체하지 않는다.
