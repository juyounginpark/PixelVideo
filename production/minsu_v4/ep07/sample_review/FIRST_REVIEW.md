# 첫 7초 샘플: 보완 후 재검수

실제 210프레임 MP4를 전부 디코드하고 S05/S06의 0.267초 간격 연속 프레임 및 360×640 대표 프레임을 직접 확인했다. 첫 버전을 그대로 통과시키지 않았다.

- 별의 이동 방향과 중심으로 향하는 민트 중력 화살표는 구분된다. 큰 별 실루엣은 이전 큐브의 원반처럼 보이는 문제를 줄였다.
- 위·아래 동일 반지름의 궤도에서 아래 별이 더 빨리 움직이는 것은 시간 순서 프레임에서 확인된다. 아래의 필요한 중력 화살표도 더 길다. 수치 재현이 아닌 정성 비교다.
- S05 후반에서 흰 진행 화살표가 상단 범례를 지나간다. S06에서도 흰 화살표가 아래 범례에 접근한다. 자동 텍스트-텍스트 검사만으로 발견할 수 없었던 편집/가림 문제다.
- P-037에 따라 S05 범례를 아래로, S06의 불필요한 진행 화살표를 제거했다. 중력 화살표 출현을 SFX와 같은 프레임으로 맞췄다.
- 영어는 본문보다 작고 같은 PIXEL_BODY를 사용한다. 360px 폭에서 문장이 읽히지만 긴 영어 구문에는 더 많은 읽기 시간이 필요할 수 있어 외부 시청자 검증이 남는다.
- 처음 샘플의 native 렌더는 107.80초(루프/캐시·프로젝션 포함), 합성·음향은 7.1초. 실제 사람의 청취와 실시간 재생은 수행하지 않았다.
