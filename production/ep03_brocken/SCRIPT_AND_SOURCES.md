# EP03 — 산에서 나를 따라 하는 거인

2026-10-12 / U-071~072. 42초 무음. 민수의 체험은 창작 각색이며 실제 촬영자의 증언이 아니다.

| 시간 | 장면 | 자막 |
|---|---|---|
| 0~3 | 민수가 팔을 들고, 큰 그림자도 동시에 같은 동작 | 내가 손을 들자, 저것도 손을 들었다. |
| 3~6 | 같은 장면 위 제목 | 산에서 나를 따라 하는 거인 |
| 6~10 | 민수의 반응 | 안개 속에 사람 형체가 서 있었다. |
| 10~15 | 옆으로 이동, 그림자도 함께 이동 | 옆으로 움직이자, 같은 방향으로 움직였다. |
| 15~19 | 자세를 낮추는 민수와 그림자 | 몸을 낮추자, 저쪽도 낮아졌다. |
| 19~23 | 넓은 산등성이 구도 | 민수 뒤에는 해가 떠 있었다. |
| 23~27 | 햇빛·사람·안개 위치 도식 | 햇빛이 민수를 지나, 앞쪽 안개에 그림자를 만든 것. |
| 27~31 | 같은 도식 | 거인의 정체는 민수 자신의 그림자였다. |
| 31~35 | 실제 촬영 사진 | 실제로 관찰되는 브로켄 현상이다. |
| 35~39 | 실제 사진 유지 | 안개 속에서는 크기를 가늠하기 어려워 거대하게 보일 수 있다. |
| 39~42 | 첫 장면의 팔 동작을 되짚고 첫 자세로 복귀 | 같이 움직일 수밖에 없었다. |

## 근거

- [영국 기상청 — Optical effects](https://weather.metoffice.gov.uk/learn-about/weather/optical-effects): 안개·구름에 드리워지는 큰 그림자.
- [Atmospheric Optics — Brocken spectre](https://www.atoptics.org.uk/droplets/globrock.htm): 낮은 태양을 등지고 안개를 바라보는 관찰자의 그림자. 익숙한 크기 비교 기준이 가려져 거대하게 보일 수 있다는 설명. 그림자와 glory는 구분한다.
- [Mick Garratt 원 촬영 기록](https://www.geograph.org.uk/photo/5150047): 2016-10-09, 영국 Little Roseberry에서 촬영. 민수의 이야기와 장소를 일치시킨 실제 사건으로 표현하지 않는다.

## 표현상의 한계

3D는 현상의 구조를 이해하기 위한 각색이다. 그림자 형상은 민수와 같은 포즈를 동시에 참조하는 평면화된 실루엣으로 만들었으며, 실제 대기 광학 시뮬레이션이 아니다. 귀신의 자율 행동이나 반응 지연은 넣지 않았다. off-axis 카메라에서 잘못 보일 수 있는 3D 광륜 장식은 제거했다.

## 독립 비평 및 수정

같은 비평 에이전트가 시안을 두 차례 확인했다. 1차 지적은 빛이 몸을 관통하는 듯한 도식, 실제 사진의 작은 단서, 거인의 머리를 가리는 제목이었다. 광선을 몸 앞에서 끝내고 뒤쪽 그림자 영역을 추가했으며, 사진 상세 확대와 제목 이동을 적용했다.

2차 판정: 글리프·제목 충돌·도식은 잠정 통과. 사진 확대 장면은 주 에이전트가 별도 이미지로 확인했다. 비평가가 움직임을 재생 확인했다고 주장하지 않는다.
