# EP02 — 영화적 카메라 / 귀여운 민수 디자인 v2

2026-10-12 / U-058~060 반영 / 무음 유지

## 디자인

민수는 큰 머리, 짧은 몸과 팔다리, 동그란 검은 눈과 작은 입, 분홍 볼로 재설계한다. 치이카와의 귀여운 비례와 간결한 감정 표현을 참고하되, 기존 민수의 머리·민트색 옷을 가진 별도의 인물로 만든다. 복셀의 기본 입체 구조에 부드러운 모서리를 더한다. 크림·민트·말린 장미색을 사용한다. 이는 특정 작품의 실제 제작 기법을 분석했다는 의미가 아닌 이번 디자인 선택이다.

UI는 크림색 둥근 자막 카드, 짧은 장소·시간 라벨, 한 번만 등장하는 제목으로 바꾼다. 큼직한 상시 남색 테두리를 제거한다. 사진은 사진 그대로 제시하고 실제 자료와 각색을 구분한다.

제목·자막에는 둥근 Jua 글꼴을 사용한다. 출처: [Google Fonts 저장소](https://github.com/google/fonts/blob/main/ofl/jua/Jua-Regular.ttf). fonts/에 원본 글꼴과 SIL Open Font License 1.1 원문을 함께 보관한다.

## 카메라

1. 어깨 너머의 빈자리 → 시선이 닿는 쪽지로 컷.
2. 제목 뒤 같은 구도에서 과거 자판기로 전환. ‘사라지기 전’ 명시.
3. 버튼 클로즈업 → 민수의 눈길 → 버튼 누르기 → 배출구 → 캔 확인. 시선과 행동이 컷의 이유가 된다.
4. 재방문 때 과거와 같은 카메라를 써 자판기의 부재를 보여준다.
5. 실제 사진과 보도 확인 뒤 첫 공간으로 돌아온다.

정사영 대신 원근 카메라를 쓰고 인물 눈높이의 중간 구도와 클로즈업을 구분한다. 얕은 심도는 얼굴과 단서 구간에 선택적으로 적용한다. 파스텔 재질에 따뜻한 주광·차가운 보조광·약한 윤곽광을 사용한다. 검은 레터박스나 화면 흔들기로 영화 느낌을 대신하지 않는다.

## 대본과 편집

v6의 쪽지→과거 구매→재방문→실제 기록→반복 흐름을 유지한다. 무음이므로 서술을 자막으로 분할한다. 물음표·과장된 감탄 대사를 채우지 않는다. 50초 편집이며 앞선 MP4는 이력으로 보존한다.

3D는 초당 12개 포즈를 렌더링해 24fps 영상에서 두 프레임씩 유지한다. 소스 .blend는 12fps이며 최종 컨테이너는 24fps다. 출력 해상도는 네이티브 720×1280이다. 24개의 서로 다른 3D 프레임을 매초 렌더한 것으로 표시하지 않는다.

## 사실·자산

민수의 체험과 공간 배치는 각색. 쪽지는 재현. 실제 사진과 출처는 v4 및 production/ep02/README.md를 따른다. 실제 사진의 공개 이용 조건은 아직 확인되지 않았으므로 로컬 검토본으로 제공한다. 사라진 이유나 자판기의 자발적 이동을 꾸며내지 않는다.

## 소스

- build.py: 기존 native 3D 자산을 불러와 캐릭터·재질·조명·카메라·애니메이션 재구성.
- compose.py: UI, 실제 사진, 자막, 무음 MP4 합성.
- MINSU_CINEMA_CUTE.blend: 수정 가능한 새 장면.
- frames_final/: 렌더링된 3D 프레임.

생성형 이미지·영상 모델은 사용하지 않는다. Python 코드는 제작 구현이며 별도의 생성형 모델 프롬프트가 아니다.
