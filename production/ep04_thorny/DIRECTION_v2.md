# P-014 — EP04 시안 피드백 반영

2026-10-12. P-013 원문 보존. 같은 소재와 메시로 재다이렉팅한다. 설명 흐름에서 늦게 나왔던 채움 조건을 입 도달보다 앞으로 옮긴다.

최종 컷 순서: 0–3 발 접촉/턱 동작 → 3–6 민수 관찰 → 6–9 생물/환경 → 9–12 입과 발 비교 → 12–15 비늘 틈 → 15–18 방사형 모세관 확산 → 18–21 피부 단면/외부 경로 → 21–24 충분한 물길 채움 → 24–27 입 주변으로 물 이동 → 27–30 턱 음수 관찰 → 30–33 등 물방울 확산 확인 → 33–36 도감 등록.

다리 상·하부 연결 메시를 이어 발이 분리되어 보이지 않게 한다. 물길 강조 큐브가 원래 치수를 유지하도록 수정하며, 생물 전체를 덮는 파랑 오브젝트를 허용하지 않는다. 발의 높이와 수면을 맞춘다. 첫 컷은 발이 물에 들어가는 짧은 이동을 가진다. 민수는 생물 쪽으로 몸과 머리를 돌린다.

물길 강조, 확대 재현 태그는 필요한 구간에만 배치한다. 대사창은 정확히 두 줄로 강제한다. 실제 프레임에서 첫 컷의 발/입과 엔딩 팝업 가림을 다시 검수한다. 해상도와 프레임 수 검증을 시청 재미 검증과 혼동하지 않는다.
