## 반영된 시안 지적

- 후반 설명의 되돌아감: 물길 채움→입 도달→턱 움직임 순서로 재정렬.
- 물길 강조 메시의 치수 오류: 원래 크기를 보존하고 생물을 덮는 큐브 제거.
- 다리 하부 연결이 빠져 발이 떨어져 보임: 연결 메시 추가, 수면/발 높이 조정.
- 첫 훅에서 입과 수면의 빈 공간이 약함: 측면 관찰로 변경. 0030 정지 시안에서 입과 발 동시 판독 개선 확인.
- 확대 물길 분기점이 대사창에 들어감: 카메라의 화면 오프셋 조정. 0470 중심 분기와 여러 갈래를 대사창 위에서 확인.
- 엔딩 민수 상체 과대/생물 작음: 생물 중심으로 전환. 팝업 등장 후에도 얼굴·발 유지.
- 브랜드 아이콘이 시리즈명과 떨어짐: 한 묶음으로 중앙 정렬.
- ‘턱 움직임 관찰’ 태그의 중복: 삭제. 강조/재현 태그는 유지.
- 0140에서 생물이 안전영역 안에 있어도 너무 작음: 민수 전신 대신 생물 근접 관찰로 교체. 민수의 일부 몸은 화면 가장자리에 두며 자막이 지목한 입·젖은 발을 우선함.

## 평가의 범위

최종 관찰 구도와 훅 샘플 시트의 추가 검토에서 독립 에이전트는 새 치명적 문제를 발견하지 않았다. 작은 샘플 시트로 턱 동작 시작 시점·반복을 확정할 수 없다는 지적은 구현 수치 검사와 별도로 기록했다. 루트 에이전트는 턱 근접 연속 샘플에서 아래턱의 위치 변화를 확인했다. 자연스러움이나 시청 지속성은 별도 미평가다.

독립 에이전트가 본 것은 합성된 정지 시안이다. 턱 움직임·방사형 확산·컷 연결의 최종 평가는 연속 프레임과 최종 영상 검수에서 따로 수행한다. 해상도·디코드 통과는 시청 유지율이나 재미의 실측 근거가 아니다. 실제 인스타그램 앱의 버튼 겹침은 미검수다.
