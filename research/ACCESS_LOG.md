# 레퍼런스 접근 기록

- 조사일: 2026-10-11, Asia/Seoul
- 조사 대상은 사용자 정정 이후 `pixel.sciences2`를 포함한 7개 계정이다.

## 조사 경로

1. 계정명 전체 일치 검색 및 인스타그램 도메인 검색: 지정 계정의 개별 릴스 결과를 확보하지 못함.
2. 계정명·표시 이름·릴스·과학 등의 확장 검색: 일부 동명 회사 및 다른 계정이 검색되었으나 동일성 근거가 없어 제외함.
3. 웹 열기 도구의 인스타그램 프로필 요청: throttled, HTTP 429 또는 도구 내부 오류. 계정 콘텐츠를 읽지 못함.
4. 공개 인스타그램 프로필 HTML 요청: 정정 이전 pixel_science와 최종 대상 중 다른 6개 계정의 메타데이터 확보. pixel.sciences2는 일반 Instagram 페이지를 반환하여 메타데이터 미확보.
5. 최종 7개 계정의 `/reels/` 공개 HTML 요청: 개별 릴스 링크·영상 재생 데이터 미확보. 6개 계정의 프로필 메타데이터만 반복 확인됨.
6. 최종 7개 계정의 `/embed/` 공개 요청: 개별 게시물 링크·영상 데이터 미확보.
7. imginn의 pixel.sciences2, zenith.whatif, pixelithm 페이지를 웹 도구로 요청: 접근 불가. 분석 근거로 채택하지 않음.

별도의 로그인 세션, 계정 인증 또는 비공개 인사이트를 사용하지 않았다. 공개 HTML의 HTTP 200 상태는 콘텐츠 접근 성공과 구별했다.

## 근거 파일

| 파일 | 포함 내용 | 주의사항 |
| --- | --- | --- |
| instagram_profile_metadata_2026-10-11.json | 최초 프로필 수집 시각(UTC), URL, 응답 상태, 메타데이터 | pixel_science는 정정 이전 대상이므로 최종 분석 제외 |
| pixel.sciences2_profile_2026-10-11.json | 정정 계정의 프로필 접근 결과 | HTTP 200이지만 계정 메타데이터 없음 |
| instagram_reels_metadata_2026-10-11.json | 최종 7개 릴스 탭의 접근 결과 | public_post_links가 비어 있음. reels_observed=0 |
| instagram_embed_access_2026-10-11.json | 최종 7개 공개 임베드 접근 결과 | post_links가 비어 있고 video_fields=0 |
| reel_observations.csv | 후속 실제 릴스 관찰표 | 현재 헤더만 존재. 관찰한 영상 없음 |

JSON의 타임스탬프는 UTC이며 한국 시각은 UTC+9다. 프로필 메타데이터는 인스타그램이 반환한 자기소개·표시 수치의 스냅샷이다. 캐시나 반올림을 독립 검증하지 못했다.

## 채택하지 않은 정보

- 정정 이전 pixel_science의 정보는 pixel.sciences2의 정보로 옮기지 않는다.
- 동명의 픽셀리즘 디자인 회사 및 다른 유튜브 채널은 연결하지 않는다.
- 일반 릴스 트렌드 기사나 다른 과학 계정은 사용자가 지정한 계정의 영상 증거를 대신하지 않는다.
- HTML 스크립트에 등장하는 `shortcode`라는 변수명은 실제 게시물 식별자가 아니다. 실제 링크를 추출하지 못했으므로 샘플로 기록하지 않는다.
