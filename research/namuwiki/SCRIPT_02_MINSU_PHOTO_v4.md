# 민수의 미스터리 — 음료를 고를 수 없는 자판기 / v4

약 45~55초 편집 목표. 녹음·루프 편집 실측 전. 민수는 가상 인물이며 구매와 재방문은 각색이다. 과장된 반응을 줄이고 실제 자료가 후반 설명을 담당한다.

## 후킹 · 첫 3초

[화면 가득 여섯 개의 MYSTERY 버튼. 민수의 손가락이 버튼 사이를 오간다.]

민수: “이거 뭐 나오는 건데?”

## 제목 · 짧게

[손가락이 버튼을 누르는 순간 제목.]

**음료를 고를 수 없는 자판기**

## 진행

[덜컹. 민수가 캔을 꺼내 돌려 본다.]

민수: “체리네.”

[캔을 따고 한 모금 마신다. 지나가다 자판기를 한 번 돌아본다.]

[‘2018년 6월’. 같은 구도. 다시 음료를 사러 온 민수가 걸음을 멈춘다. 자판기가 없다.]

민수: “없어졌네.”

[난간에 붙은 쪽지를 발견한다.]

**Went for a walk.**
**산책 갔음.**

[민수가 쪽지에서 빈자리로 시선을 옮긴다. 추가 감탄 대사 없이 잠깐 멈춘다.]

## 설명 · 실제 자료로 전환

[애니메이션에서 실제 자판기 사진으로 전환. 사진 크레딧: SDOT / Seattle Met 게재.]

내레이션: “시애틀에 실제로 있던 자판기다. 누가 운영하는지는 공개되지 않았고, 전기를 대주던 옆 가게 직원들도 주인은 모른다고 했다.”

[2018년 사라짐을 보도한 기사 제목·날짜를 출처와 함께 제시한다. 원본 지면 사용 전 권리 확인; 대안은 출처가 붙은 요약 카드.]

내레이션: “인근 보도 공사가 진행되던 2018년 6월, 자판기는 사라졌다. ‘산책 갔음’이라는 쪽지를 남긴 채.”

## 루프 엔딩

[실제 자판기 사진으로 돌아와 버튼 부분을 확대한다.]

내레이션: “버튼에는 음료 이름 대신, ‘미스터리’라고만 적혀 있었다.”

[실제 버튼의 배열과 위치를 첫 애니메이션 버튼에 맞춘다. 사진에서 애니메이션으로 전환한 직후 종료.]

→ 처음의 손가락 움직임과 “이거 뭐 나오는 건데?”로 연결.

## 실제 자료와 확인 상태

- 직접 확인한 실물 사진 참고본: [vending_sdot.jpg](assets/vending_sdot.jpg). 낡은 자판기 전체, 2행 3열 노란 버튼, 난간을 볼 수 있다. 사진의 가격은 75센트이므로 2018년의 1달러 가격을 입증하는 사진처럼 사용하지 않는다. 정확한 촬영일은 미확인, 자막은 '실제 자판기 사진'으로 표시한다.
- 사진 게재 페이지: [Seattle Met, 2023-08-28](https://www.seattlemet.com/news-and-city-life/2023/08/whatever-happened-capitol-hill-mystery-coke-machine). 게재 크레딧은 Courtesy SDOT. 원본 이용 조건·게시 허락은 미확인이다. 다운로드는 조사 참고본이며 게시 가능한 최종 자산으로 확정한 것이 아니다.
- 같은 기사 상단의 녹색 물음표 이미지 `assets/vending_reference.jpg`는 편집된 기사 이미지다. 현장 원본 사진처럼 사용하지 않는다.
- 버튼·음료 사례: [Seattle Met, 2018-02-27](https://www.seattlemet.com/news-and-city-life/2018/02/the-case-of-capitol-hills-mystery-soda-machine).
- 당시 사라짐: [CHS, 2018-06-30](https://www.capitolhillseattle.com/2018/06/eyewitnesses-capitol-hills-mystery-soda-machine-has-disappeared/).
- 쪽지의 문구: [Atlas Obscura, 2018-07-02](https://www.atlasobscura.com/articles/seattle-mystery-soda-machine-is-missing). 실제 쪽지 사진은 별도 확보하지 못했으므로 진행부의 쪽지는 재현 그래픽이다. 실물 사진이라고 표시하지 않는다.
- 공사 시기와 사라짐의 동시성을 설명했으며, 공사가 제거의 원인이라고 확정하지 않는다. 현재 행방을 단정하거나 합성 여행 사진을 실제 이동 증거로 쓰지 않는다.

소재의 핵심은 기묘한 지역 이야기다. 초자연 현상이나 실제 범죄로 확대하지 않는다. 영상은 아직 제작하지 않았다.
