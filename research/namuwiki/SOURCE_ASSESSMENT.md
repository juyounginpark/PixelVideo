# 자연과학 미스터리 소재 출처 검토

사용자 요청 U-030, U-031. 2026-10-12. 현재 제작 길이는 **30~60초**다. 1분에 맞추기 위해 이야기를 늘리지 않는다. 기존 60초 초안은 이력으로 유지한다.

원본: https://namu.wiki/w/미스터리%20관련%20정보/자연과학%20관련%20정보

웹 도구에서는 접근 오류였으나 일반 HTTP 요청으로 본문을 확보했다. listing.html, listing.txt에 보존했다. 소재 탐색용 색인으로 활용할 가치가 있다. 이 문서의 제목과 설명만으로 과학적 사실·현재 미해결 여부를 확정하지 않는다. 논문·연구기관·공식 관측 자료를 확인한 뒤 대본으로 만든다.

실제 확인된 항목 중 음펨바 효과, 브라질너트 효과, 암흑물질은 물체·상태 변화로 시각화하기 좋은 검토 대상이다. 최종 검증·선정은 아직 완료하지 않았다. 피해가 있는 토네이도 사건, 실종·사망, 의학적 체험·증상, 미확인 목격담은 기존 필터를 적용한다.

추천 제작 구조는 질문하는 인물과 관찰·설명하는 인물의 역할극이다. 이는 새 제작 형식이며 역사적 실제 대화가 아니다. 관찰된 현상과 가설을 구분한다. 기: 이상한 현상 제시 / 승: 인물의 예상 / 전: 예상과 다른 관찰·설명 / 결: 확인된 부분과 남은 질문. 미스터리 분위기를 위해 과학적 설명을 숨기거나 새 초자연 반전을 넣지 않는다.

선별 순서: 위키에서 이름·핵심 질문 확보 → 사용자 제외 기준 → 1차 자료에서 현상·조건·현재 상태 확인 → 30~60초에 보여줄 변화 하나와 질문 하나 선정 → 역할극 대본. 조회수/시간은 해당 위키 항목에서 확보하지 못했으므로 괴담 게시판의 지표를 대입하지 않는다.

## 외부 근거 1차 대조

- 브라질너트 효과: 맨체스터대학교 2021년 연구 소개에서 3D 촬영으로 큰 견과가 위로 올라가는 과정을 설명한다. 위키의 미해결 강조를 대본에 그대로 옮기지 않는다. https://www.manchester.ac.uk/about/news/scientists-crack-the-brazil-nut-puzzle-how-do-the-largest-nuts-rise-to-the-top/
- 암흑물질: NASA Hubble 설명은 중력적 효과를 근거로 추론하고 정확한 정체는 모른다고 구분한다. https://science.nasa.gov/mission/hubble/science/science-behind-the-discoveries/hubble-dark-matter/
- 음펨바 효과: 2016년 Scientific Reports 실험 논문은 특정 통제 조건에서 주장에 부합하는 증거를 찾지 못했다고 보고한다. 단일 논문을 전체 연구의 최종 결론으로 일반화하지 않는다. 대본 선정 전 실험 정의·조건과 다른 연구까지 검토해야 한다. https://www.nature.com/articles/srep37665

이 대조는 소재의 기본 검증 부담을 확인한 것이며 전체 목록 팩트체크나 후보별 대본 검증 완료가 아니다.
