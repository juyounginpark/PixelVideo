# 민수의 미스터리 — 정체불명의 자판기 / v3

사용자 확정 구조: 후킹 → 제목 → 진행 → 설명 → 처음으로 반복되며 끝.
약 50~60초 목표, 녹음 실측 전. 민수의 행동과 대사는 가상 재연이다. 2018년 당시를 배경으로 하며 사실 근거는 SCRIPT_02_MYSTERY_VENDING_MACHINE.md에 기록된 보도다.

## 대본

### 후킹 · 0~3초

[동전이 들어가는 소리. 민수의 손이 버튼 앞에서 멈춘다. 버튼마다 MYSTERY.]

민수: “잠깐. 나 지금 뭘 산 거지?”

### 제목 · 3~5초

[민수의 손과 자판기를 그대로 둔 채 제목을 짧게 겹친다.]

**민수의 미스터리: 정체불명의 자판기**

### 진행 · 5~27초

[민수가 위에서 아래로 버튼을 훑는다. 전부 같은 표시다.]

민수: “콜라… 사이다… 그런 게 아예 없네?”

[하나를 누른다. 덜컹. 체리 콜라 캔을 집어 든다.]

민수: “아, 랜덤 뽑기구나.”

[캔을 보다가 자판기를 다시 바라본다.]

민수: “근데 이거, 누가 채워 놓는 거야?”

[‘2018년 6월’. 같은 장소의 빈자리. 민수의 손에 들린 동전.]

민수: “어? 자판기 어디 갔어?”

[난간 쪽지 근접. Went for a walk. / 번역 자막: 산책 갔음.]

민수: “산책? …누가?”

### 설명 · 27~48초

[버튼·옆 가게·공사 중인 보도를 짧게 연결한다. 사람을 범인처럼 묘사하지 않는다.]

내레이션: “실제로 시애틀에 있던 자판기다. 여섯 버튼이 모두 미스터리였고, 운영자는 공개되지 않았다. 전기를 대주던 옆 가게 직원들도 주인은 모른다고 했다.”

내레이션: “2018년, 인근 보도 공사 무렵 자판기는 사라졌다. 빈자리에는 ‘산책 갔음’이라는 쪽지가 남았다.”

### 루프 연결 · 48~끝

[‘사라지기 전’이라는 작은 표식. 빈자리와 같은 구도로 자판기가 있던 시점으로 돌아온다. 민수가 처음 동전을 넣기 직전의 자세다.]

내레이션: “민수가 처음 궁금했던 건, 딱 하나였다.”

[민수가 동전을 투입구에 놓는다. 동전이 손을 떠나는 프레임에서 종료.]

→ 첫 프레임의 동전 소리와 연결.

→ 민수: “잠깐. 나 지금 뭘 산 거지?”

## 편집과 근거

- 마지막 동전 투입 동작과 첫 동전 소리는 하나의 연속 동작으로 설계한다. 대본상의 루프이며 실제 프레임·음성 연결 검증은 미실행이다.
- 첫 장면의 관심은 상품, 진행의 관심은 운영자, 후반의 관심은 행방으로 바뀐다. 루프에서 첫 구매 장면을 다시 본다.
- 회상 전환을 명시해 자판기가 실제로 돌아왔다는 새 사건을 만들지 않는다.
- 체리 콜라는 당시 보도된 음료 사례다. 민수의 특정 구매·방문·쪽지 발견은 재연이다.
