# P-008 — 시애틀 미스터리 자판기 대본

사용자는 제목과 흥미 위주로 유연하게 전개되는 30~60초 역할극을 원한다. 시애틀 미스터리 자판기 한 편을 작성한다. 미스터리 버튼의 선택 불가능성→운영자에 대한 궁금증→2018년 사라짐과 남은 메시지로 관심을 이동한다. 초마다 정보를 억지로 배분하거나 설명자와 질문자의 강의형 문답으로 만들지 않는다. 짧은 가상 인물 대화와 필요한 내레이션을 결합한다.

기록으로 확인되는 버튼·운영 상태·제거 시점·메시지·후속 정보를 근거로 한다. 물건이 순간이동하거나 저절로 걸었다는 재현을 만들지 않는다. 아무도 보충 장면을 본 적 없다는 주장은 검증 없이는 사용하지 않는다. 현재도 영원히 미해결이라는 단정을 피하고 보도의 시점을 명시한다. 인물 대사는 각색으로, 쪽지의 번역은 번역으로 구분한다. 제목·대본·짧은 화면 지시·출처·각색 범위를 Markdown에 저장한다. 영상 길이는 녹음 전 예상이며 영상은 제작하지 않는다.
