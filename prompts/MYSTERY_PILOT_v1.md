# P-007 — 역할극 컨셉 파일럿 1편

U-037·U-038에 따라 기존 검토 주제 '데스밸리의 움직이는 돌'로 30~60초 역할극 한 편의 컨셉과 대본을 작성한다. 목표 약 45초, 녹음 전 추정으로 표시한다. 두 가상 인물이 현장에서 관찰하고 예상과 다른 단서를 확인하는 구조로 한다. 대사·등장인물·상황은 새 각색임을 명시하며 실제 연구자의 발언으로 제시하지 않는다.

과학적 작동 원리는 1차 관측 논문으로 확인한다. 이미 설명된 현상을 현재 미해결 또는 초자연 현상으로 표현하지 않는다. 기승전결은 이동 흔적 발견→인물의 추측→얇은 얼음과 바람 관찰→이동 원리 이해로 잡는다. 원문에 없는 범죄·피해·초자연 반전을 붙이지 않는다.

기존 두 레퍼런스에서 확인한 블록 질감 3D, 상태 비교, 질문과 다음 장면의 연결, 전면 세로 화면과 간결한 대화 자막을 응용한다. 새로운 색상·구도·음향 제안과 레퍼런스 관찰 사실을 구분한다. 컨셉 설명, 시간별 화면·대사, 디자인 규칙과 근거를 제시한다. 실제 영상·음성 제작은 별도 요청 전 실행하지 않는다.
