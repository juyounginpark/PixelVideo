# P-016 — MINSU V2 / EP04 / BGM·SFX

2026-10-12. 사용자 V2 및 BGM/SFX 명세를 우선한다. 이전 버전은 보존한다.

Blender/Pillow/FFmpeg를 유지하고 네이티브 3D로 EP04를 재제작한다. 머리가 약 40%인 민수, 사막의 납작한 가시도마뱀, 각진 텍스처와 부드러운 조명, 전체 화면 구도를 사용한다. 9컷 36초의 접촉→반응→관찰→비늘 확대→모세관 이동→외부 물길→입 도달→발견→결론으로 진행한다. 행동과 원인·결과를 자막 전에 보여준다. 확대 모식도는 실제 유체 계산으로 가장하지 않는다. 같은 메시·표정 세트·리그를 유지한다. UI는 필요한 사건에만 띄우고 흰 굵은 자막·핵심 민트색을 사용한다. 540×960 내부 렌더를 2배 nearest 확대한다. 시안과 사건 전후를 확인한 후 전체 렌더한다.

음악은 100BPM의 가사 없는 오리지널 칩튠/플럭 연주 루프로 만든다. 저음은 삼각파 계열, 높은 음은 부드러운 플럭, 드럼은 짧고 낮은 합성 퍼커션. 외부 샘플이나 기존 멜로디를 복제하지 않는다. 메인 곡은 한 곡, 0.4초 페이드인·0.8초 페이드아웃. 이벤트에서만 작은 물방울·질문 블립·UI 팝·발견 차임을 추가한다. 주요 SFX에 4dB 덕킹, BGM/SFX/최종 믹스를 별도 저장한다. TTS를 만들지 않는다. LUFS·true peak·루프 경계·AAC와 전체 디코드를 확인한다. 원곡/효과음 제작 소스와 메타데이터를 함께 남긴다.
