# P-011 — 민수 자판기: 실제 자료와 시각적 루프 / v4

사용자 요청: 자연스러운 짧은 대사, 마지막 실제 사례·사진, 후킹→제목→진행→설명→첫 장면으로 반복. 기존 시애틀 자판기 보도를 기반으로 30~60초 대본을 개정한다. 민수는 가상 인물이고 체험은 재연이다. 감탄·수사적 질문·인위적인 연결 내레이션을 줄이고 손·시선·빈자리로 정보를 전달한다. 마지막 설명에는 출처가 있는 실제 자판기 사진과 당시 보도 자료를 배치한다. 실물 사진의 버튼을 첫 애니메이션 버튼 구도에 맞춰 루프한다. 실물 사진과 재현 이미지를 혼동하지 않는다. 사진에서 실제 확인하지 않은 디테일은 확정하지 않는다. 기록에 없는 희귀 음료·단종 음료·보충 목격담·순간이동을 추가하지 않는다. 사진 이용 조건과 실제 편집 검증은 완료 여부를 명시한다.
