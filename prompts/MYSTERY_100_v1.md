# P-006 — 레퍼런스 기반 미스터리 주제 100선

U-032. 사용자 제공 나무위키 미스터리 관련 정보 메인과 실제 확인한 하위 목록을 소재 색인으로 사용해 서로 다른 주제 100개를 선정한다. 기존 실제 범죄·사고·피해 사건, 정치·민감한 개인사·과도한 수위 제외를 유지한다. 자연현상·고고학 유물의 존재 자체는 피해 사건으로 분류하지 않는다. 종교 갈등·음모론·의학 주장도 제외한다.

각 행에 고유 소재명, 새로 작성한 질문형 후킹 초안, 눈에 보일 장면 또는 역할극 갈등, 원문 목록 링크·항목명, 검증 상태를 남긴다. 30~60초 역할극을 목표로 예상과 관찰의 충돌·시각적 변화·정보 격차가 있는 주제를 우선한다. 후킹은 새 제작 문구이며 원문의 인용이나 검증 완료 사실이 아니다. 조회 성과는 보장하지 않는다. 같은 소재를 질문만 바꿔 중복하지 않는다.

위키의 존재를 과학적 진위 검증으로 대체하지 않는다. 목격담·전승·미해결 주장·해결된 현상은 구분하고 필요한 검증 조건을 표시한다. 역사적 대화와 등장인물 행동을 사실처럼 창작하지 않는다. 선정 가능한 원문 항목이 부족하면 확인한 연결 하위 목록으로 범위를 넓히고 출처를 기록한다. 실제 확인하지 않은 링크·자료를 읽었다고 주장하지 않는다. 100선 Markdown 및 CSV/JSON으로 저장하고 전체 목록을 사용자에게 제시한다.
