# P-012 — 레트로 복셀 과학 릴스 공통 감독 프롬프트

2026-10-12. 재사용 템플릿. 이번 구현에 적용하며 외부 생성형 영상 모델을 호출한 것은 아니다.

입력: 소재, 검증한1차자료, 핵심행동, 캐릭터에셋, 출력길이, 기존에제작한주제목록.

RETRO_VOXEL_MASTER_SPEC.md와 RETRO_VOXEL_PRODUCTION_GUIDE.md를 우선한다. 유리개구리 레퍼런스의 낮은 해상도 게임 관찰 느낌과 RPG 정보창의 역할을 참고하되, 기존 브랜드·문구·소재·컷 순서를 복제하지 않는다.

첫2초 안에 행동으로 관찰 가능한 놀라운 현상을 보여준다. 시청자가 무엇을 봐야 하는지 제목보다 3D 장면이 먼저 전달해야 한다. 캐릭터의 반응, 질문, 관찰, 원인 설명, 첫 현상 연결, 한 문장 결말을 이어라. 매 컷은 직전 컷의 상태를 이어받고 새로운 사건이나 정보를 추가한다.

컷별로 시간, A~E카메라종류, 시작/끝구도, 관찰대상, 핵심키프레임, Idle, 새로운정보, 대사2줄, 세계태그, 출처, 표현한계를 표로 작성한다. 같은 질문을 세 번 반복하거나 제목을 그대로 다시 말하는 대사를 쓰지 않는다. 움직임 없는 컷을 연달아 배치하지 않는다.

1080×1920·30fps·35~45초를 기본으로 한다. 3D를 낮은 해상도로 렌더링하고 UI를 독립 합성한다. 검정22.5%헤더, 독자시리즈명과도감아이콘, 블루배너의흰보조문구/노란질문, 고정RPG대사창의남색첫줄/민트둘째줄을 공통 컴포넌트로 사용한다. SNS UI, 제작 방식, 대화 이력, 의미 없는 진행 문구를 넣지 않는다.

직육면체·쐐기·낮은 폴리곤, Flat Shading,16~64px텍스처를 사용한다. 과도한광택·현실반사·DOF·Pixar형매끈한모델을 사용하지 않는다. 같은 생물은 모든 컷에서 같은 메시·재질·색상을 유지한다. 생물의 실제 형태와 움직임을 먼저 참고한다. 중요한 현상은 키프레임과 이동·파티클·색상변화로 구현하되 도식적 표현을 사실과 구분한다.

확정된 사실과 가설을 분리한다. 피부·혈관·기관 등 내부를 설명할 때 실제 구조와 모순되는 그림을 그리지 않는다. 논문에 없는 섭취·이동 메커니즘을 만들어 확정하지 않는다. 시각성이 낮은 소재는 제작하지 않는다.

정지 시안만 보고 완성도를 승인하지 않는다. 행동의 시작/중간/끝과 시선→머리→발견의 연결을 검수한다. 관절이 떨어지거나 대사와 동작 시점이 어긋나면 고친다. 검수 결과와 미확인 항목을 기록하고 프롬프트와 결과 경로를 PROMPT_LOG.md에 남긴다.
